# BrainDuck

Это высокоуровневый язык программирования, который компилируется в код на BrainF*ck.


## Выделение статической памяти

Выделение статической памяти происходит ещё до выполнения программы, при помощи инструкций def. Для освобождения памяти используется инструкция del.

```BrainDuck
def[3] a;
```

Этот фрагмент кода зарезервирует 3 байта памяти под названием "a".

```BrainDuck
def[1] b;
def[2] c;
```

Последующие объявления будут занимать следующие свободные ячейки памяти.

```BrainDuck
del b;
```

Инструкция del свобождает пространство, НЕ ОЧИЩАЯ ПРИ ЭТОМ ЗНАЧЕНИЕ ХРАНЯЩИЕСЯ В ЯЧЕЙКЕ.

```BrainDuck
def[1] d;
def[1] e;
```

Последующие объявления будут размещаться в первый свободных ячейках памяти, в которые они помещаются.

Таким образом, ячейки будут зарезервированы следующим образом:

[ A, A, A, D, C, C, E ... ]


## Сложение в двоичной системе

Для сложения я сочинил вот такую конструкцию: 

```BrainFuck
+>+>+> >{'+' if I1}>{'+' if I2}>{'+' if I3}<< [>>>>+<<<<<]  <[>]  >> [>>>+<<<<<] <<[>] >>> [>>+<<<<<] <<<[>] >[>] + [<] >>>>> [+<+>>+<] >[+<+>]< <+ <+<+<[>]<+  <<<<[>]
```

Попытаюсь объяснить логику этого алгоритма. Но перед этим объясню, какую именно логику я хотел в нём реализовать. 
Из таблицы истинности для полного сумматора, выходит следующие: младший бит результата равен четности входящий переменных, а старший бит результата равен инверсии младшего бита во всех случаях кроме двух. Эти два случая: 000 -> 00, 111 -> 11, и них видно, что старший бит равен младшему. В моём алгоритме я сначала вычисляю чётность, а после проверяю эти два исключения.

Сначалая я инициирую три подряд идущих единицы ```[x0:1, x1:1, x2:1, x3:0, ..., xn:0]```, которые используются для возращения курсора в исходное положение. В будущем я буду использовать конструкции типа: ```<[>]``` именно для того, чтобы поместить курсор на индекс 3. 

Курсор оказывается на индексе x3.

```BrainFuck
+>+>+>
```

Далее я помещаю три входных значения сумматора на индексы 4, 5 и 6 соответственно. Таким образом выходит ```[x0:1, x1:1, x2:1, x3:0, x4:I1, x5:I2, x6:I3, x7:0, ..., xn:0]```. 

Курсор оказывается на индексе x4.

```BrainFuck
>{'+' if I1}>{'+' if I2}>{ '+' if I3 }<<
```

Далее мы начинаем проверять на чётность входящие значения сумматора. Для этого каждое значение проверяем на равенство единицы, и в этом случае меняем значение счётчика по индексу x8, а после возвращаемся к индексу x3. В противном случае мы просто возвращаемся к индексу x3. 

Возможность оказаться именно в индексе x3 в обоих случаях, достигается именно, при помощи шага в лево до встречи единицы.  


```BrainFuck
[>>>>+<<<<<]  <[>]
```

Аналогично делаем для оставшихся двух входных значений

```BrainFuck
>> [>>>+<<<<<] <<[>] >>> [>>+<<<<<] <<<[>]
```

В конце курсор обязательно, оказывается по индексу x3, а по индексу x8 храниться чётность трёх входных значений, при том сами входные значения остаются не изменными.

Далее мы проверяем случай где все три входных значения равны 1, так как это исключение при котором старший результирующий бит таблицы истинности не равен инверсии младшего бита. Результат записываем под индекс x7.

```BrainFuck
>[>] + [<]
```

Далее мы копируюем значение из x8 в x7 и x9 (в x9 для того, чтобы после вернуть его в x8).

```BrainFuck
>>>>> [+<+>>+<] >[+<+>]<
```

Далее мы инвертируем значение под индексом x7. Это и есть старший бит, в котором до этого мы уже успели положить результат проверки на 111. 

```BrainFuck
<+
```

После мы проверяем на 000, для чего возращаемя и инвертируем значения под индексами I2 и I3, но не трогаем I1, так как к этому моменту, если вариант 000, то в этих значениях должно было находиться следующие: I1:1, I2:0, I3:0. После мы опять возвращаеся в x7 и инвертируем там значение.

После возвращаемся к индексу x3.

```BrainFuck
<+<+<[>]<+ <<<<[>]
```

Итог: x7 - старший бит; x8 - младший бит


## Цикл с переменной

Для реализации такого цикла, необходимо в каждой итерации проверять head на не равенство нулю. 
Для того чтобы проверить равняется ли нулю все, необходимо снала их всех инвертировать, а потом использовать ```[>]```.
