# BrainDuck

Это высокоуровневый язык программирования, который компилируется в код на BrainF*ck.


## Выделение статической памяти

Выделение статической памяти происходит ещё до выполнения программы, при помощи инструкций def. Для освобождения памяти используется инструкция del.

```BrainDuck
def[3] a;
```

Этот фрагмент кода зарезервирует 3 байта памяти под названием "a".

```BrainDuck
def[1] b;
def[2] c;
```

Последующие объявления будут занимать следующие свободные ячейки памяти.

```BrainDuck
del b;
```

Инструкция del свобождает пространство, НЕ ОЧИЩАЯ ПРИ ЭТОМ ЗНАЧЕНИЕ ХРАНЯЩИЕСЯ В ЯЧЕЙКЕ.

```BrainDuck
def[1] d;
def[1] e;
```

Последующие объявления будут размещаться в первый свободных ячейках памяти, в которые они помещаются.

Таким образом, ячейки будут зарезервированы следующим образом:

[ A, A, A, D, C, C, E ... ]
